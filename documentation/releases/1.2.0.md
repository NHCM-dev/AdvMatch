# AdvMatch 1.2.0

Changes since [`8285d9d`](https://github.com/NHCM-dev/AdvMatch/commit/8285d9d2422c78fa9fdf7e2fed9b09c0c077e174).

## English

- Add runtime contract price-protection configuration to the C++ and Java SDKs: `contracts().configureProtection(symbol, rate)`. Rates use millionths; `100000` means 10%, and `0` disables the exchange execution band.
- Keep explicit market-order price caps and collateral checks active when protection is disabled. Margin reservations retain a bounded mark-price estimate, and liquidation execution remains bounded.
- Persist protection changes through checkpoints and WAL replay. Add regression coverage for disabling, restoring, invalid configuration, execution caps, insufficient collateral and recovery.
- Update SDK packaging and benchmark tooling to 1.2.0, with matching API generation and concise bilingual integration documentation.
- Add the repository's GPL-3.0 license file.

### Compatibility and artifacts

Update the Java SDK and native libraries together. Older engines do not understand the new protection command; retain a complete compatible backup before upgrading or downgrading. No automatic data reset is required.

- Windows amd64 native SDK: `AdvMatch-1.2.0-Windows-AMD64.zip`.
- Java SDK with bundled Windows amd64 native libraries: `advmatch-1.2.0.jar`; Java 21 or later.

## 简体中文

- C++ 与 Java SDK 新增运行时合约价格保护配置：`contracts().configureProtection(symbol, rate)`。数值以百万分之一计，`100000` 表示 10%，`0` 关闭交易所成交价格保护。
- 关闭保护后仍校验显式市价保护价和抵押资金；保证金预留采用有界标记价估算，强平执行也保留价格边界。
- 保护设置支持检查点和 WAL 恢复，并补充关闭、恢复、非法数值、成交限价、资金不足及恢复测试。
- SDK、基准工具和接口生成同步更新到 1.2.0，完善简洁的中英文接入文档。
- 仓库加入 GPL-3.0 许可证文件。

升级时同时替换 Java SDK 与原生库。旧引擎无法读取新增保护配置命令；升级或降级前保留完整兼容备份。无需自动清空现有数据。发布产物为 Windows amd64 原生 SDK ZIP 和 Java SDK JAR，Java 最低要求 21。
